# Siddiqa Sabir — Automation Portfolio Banner

## Files
- `index.html` — banner structure and SVG automation icons
- `style.css` — teal/cyan visual design, circuits, glow, typography and responsive layout
- `script.js` — animated particles and mouse interaction

## Run
1. Put all three files in the same folder.
2. Open `index.html` in VS Code with Live Server, or double-click it.
3. The banner works without any image background.
4. Internet is only used for the Google Fonts import. The visual background itself is CSS + SVG + JavaScript.

## Main visual idea
The name and introduction stay in the CENTER instead of using the common “text left / image right” portfolio layout. Automation/security nodes and circuit paths surround the content so the technology is part of the whole background.
